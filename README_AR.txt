تطبيق مواقيت الصلاة - مشروع Android

طريقة البناء:
1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (لا ترفع ملف ZIP وحده إذا كنت تريد تشغيل البناء مباشرة).
2) افتح تبويب Actions في GitHub.
3) اختر Build Android APK ثم Run workflow.
4) بعد اكتمال البناء افتح نتيجة التشغيل ونزّل Artifact باسم MawaqitPrayerApp-debug.

مهم:
- هذه نسخة أولية ولم يتم اختبار بنائها على جهازك.
- الأوقات تُدخل يدوياً بصيغة 24 ساعة حسب تقويم مدينتك.
- النسخة الحالية تستخدم نغمة منبه الهاتف الافتراضية، وليست ملفي الأذان اللذين أرسلتهما سابقاً؛ لم تتوفر ملفات الصوت الأصلية في جلسة إعادة إنشاء الأرشيف.
- أندرويد قد يتطلب منح صلاحية الإشعارات والمنبهات الدقيقة، وقد تؤثر قيود البطارية على التنبيهات.
- لإضافة الأذان: أنشئ app/src/main/res/raw وضع الملفين adhan1.mp3 وadhan2.mp3، ثم يلزم تعديل الخدمة لتشغيل الملف المختار.
